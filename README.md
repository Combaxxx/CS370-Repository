# CS370-Repository

## Project Two: Pirate Intelligent Agent
### Project Overview
For this project, I worked on developing an intelligent pirate agent that could navigate through a maze to find treasure using reinforcement learning and neural networks. The goal was to train the agent to make decisions based on its environment rather than following a predetermined path. I was provided with starter code that included the maze environment, experience replay functionality, and a partially completed Jupyter Notebook. My responsibility was to complete the Q-training algorithm that allowed the pirate to learn from its actions and improve its decision-making over time. This involved implementing training logic, adjusting parameters, and testing how the agent performed as it attempted to reach the treasure.

### What Do Computer Scientists Do and Why Does It Matter?
Computer scientists develop solutions to problems using programming, algorithms, and technology. Their work involves more than just writing code because they also have to understand problems, evaluate possible solutions, and determine how those solutions will affect people. In this project, I learned how artificial intelligence can be used to solve problems that require decisions rather than just following fixed instructions. This matters because similar techniques can be applied to robotics, automation, navigation, and other systems that need to adapt to changing conditions.

### How Do I Approach a Problem as a Computer Scientist?
I approach problems by breaking them into smaller parts, understanding what each component needs to accomplish, and testing possible solutions. During this project, I had to understand how the maze environment worked, how the agent received rewards and penalties, and how the neural network used that information to make decisions. When I encountered errors or unexpected results, I reviewed the code, adjusted parameters, and tested the program again. One of the biggest lessons I learned was that getting a program to run does not necessarily mean it is working correctly. Testing and evaluating the results are just as important as implementing the solution.

### What Are My Ethical Responsibilities to the End User and the Organization?
As a computer scientist, I have a responsibility to develop software that is reliable, secure, and designed with the user's best interests in mind. This is especially important with artificial intelligence because these systems can make decisions that are difficult for users to understand. Developers need to consider the accuracy of their models, the possibility of biased results, and the consequences of incorrect decisions. Organizations also have a responsibility to be transparent about how AI systems operate and how user information is handled. This course helped me understand that responsible development means considering these concerns throughout the development process rather than waiting until a system is finished.
